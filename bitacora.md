# Bitácora del proyecto: Compañeros de computadora

## 1. Idea inicial

El proyecto surgió a partir de una necesidad concreta del laboratorio de tecnología: organizar de manera rápida y aleatoria las parejas de estudiantes que trabajan en computadora. La intención fue crear una herramienta simple, visual y útil para el uso cotidiano docente.

## 2. Objetivo del proyecto

Desarrollar una aplicación web sencilla que permita ingresar listas de varones y mujeres para generar parejas aleatorias. Además, se buscó que la herramienta tuviera una estética atractiva, moderna y relacionada con el área de tecnología.

## 3. Primera versión

En una primera instancia se desarrolló una versión básica con:

* dos campos de texto para ingresar nombres
* un botón para generar parejas
* un botón para limpiar los campos
* un sector para mostrar el resultado

La lógica inicial permitía emparejar un varón con una mujer hasta agotar una de las listas.

## 4. Mejora en la lógica del programa

Luego se mejoró la funcionalidad para que, cuando se terminaran las parejas mixtas, el sistema siguiera armando parejas aleatorias con quienes quedaban sobrantes. De esta manera, la herramienta resultó más flexible y útil para situaciones reales del aula.

## 5. Organización del proyecto

El proyecto se estructuró en archivos separados:

* `index.html` para la estructura
* `style.css` para el diseño visual
* `script.js` para la lógica del programa
* carpeta `imagenes` para los recursos gráficos
* `README.md` para la presentación del repositorio

Esta organización permitió un desarrollo más claro y ordenado.

## 6. Diseño visual

Se trabajó una estética oscura con inspiración tecnológica:

* fondo negro
* botones naranjas
* títulos en verde brillante
* tipografía estilo código

Se realizaron varias pruebas de color y distribución visual hasta encontrar una identidad más coherente con la idea del proyecto.

## 7. Creación e incorporación del logo

Se diseñó un logo con dos estudiantes frente a una computadora, relacionado con el trabajo colaborativo en programación. Más adelante se ajustó el fondo del logo a un tono claro para que contrastara mejor con la interfaz oscura del sitio, especialmente en la versión móvil.

## 8. Ajustes de maquetación

Durante el proceso se hicieron varios cambios de posición y tamaño:

* reubicación del logo
* ajuste del título principal
* mejora del aspecto de las etiquetas de listas
* corrección del ancho de cajas y botones

Estos cambios buscaron mejorar la armonía visual y la legibilidad.

## 9. Adaptación responsive

Se detectó que en celular la interfaz presentaba problemas de superposición y desborde. Por eso se agregaron reglas responsive con `@media`, logrando:

* logo centrado en móvil
* listas en columna
* botones acomodados verticalmente
* mejor ajuste general del contenido al ancho de pantalla

## 10. Publicación del proyecto

Una vez terminada una versión funcional, el proyecto se subió a GitHub y luego se publicó en Vercel para poder acceder a la aplicación online desde distintos dispositivos.

## 11. Aprendizajes

A lo largo del desarrollo se pusieron en práctica contenidos de:

* HTML
* CSS
* JavaScript
* Git y GitHub
* despliegue con Vercel
* diseño responsive

También se fortaleció la idea de escalabilidad, ya que el proyecto comenzó como una herramienta simple y luego se pensó en futuras mejoras.

## 12. Posibles mejoras futuras

Como continuación del proyecto, se pensaron nuevas funciones:

* guardar listas de alumnos de manera local y privada
* generar equipos aleatorios de 3, 4 o más integrantes
* crear un orden aleatorio para turnos o préstamos
* integrar varias herramientas en una misma aplicación o dashboard para organización del aula

## 13. Valor del proyecto

Más allá de su posible uso académico, este proyecto tiene valor práctico real, ya que puede utilizarse en el aula para facilitar la organización de actividades con computadoras de forma rápida, visual y justa.
